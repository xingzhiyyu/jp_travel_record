# 轨道行程记录生成器

## 与当前仓库渲染器衔接

新增 **导出视频行程** 按钮：导出 `时间 | 线路名 | 起点 -> 终点 | day/night`，
保留日文原名，每段明确昼夜，可交给本仓库 Python 解析器。缺少且无法从相邻行唯一补齐的端点会阻止导出。
格式兼容后仍需做线路/地理核对，详见 [执行流程](../docs/WORKFLOW.md)。
下文的旧格式只适用于原 lvji 渲染器；旧 TXT、复制、预览及导入仍沿用旧格式。
云端提供精简静态版，使用已生成的 data.js，不附带构建脚本、测试脚本、源数据库或旧审计资料。
已有的 scripts/ 和 data/source/ 可继续保留在本地，它们已被 Git 忽略，不会随正常提交上传。
预生成站表的来源与再分发许可仍需确认；移除源数据库不代表衍生站表已获得再分发授权。

在 UI 里选择「线路 / 起点 / 终点」，生成 lvji 行程格式的 txt（每行一段：`线路名 起点 → 终点`，另可插入步行 / 公交 / 打车标签段）。
覆盖日本全国 8 个地区：北海道 · 东北 · 东京都市圈（関東）· 中部 · 关西（近畿）· 中国地方 · 四国 · 九州，含新干线、地铁、私铁、路面电车与 BRT。

## 用法

**双击 `index.html` 即可**，纯静态离线运行，无需联网或安装任何环境。
（也可在该目录跑 `python3 -m http.server 8642` 后用浏览器打开 `http://127.0.0.1:8642/`。）

1. 左侧依次选 **地区 → 线路 → 起点 → 终点**（线路按公司分组，站名带中文注音；全国 576 条线路可在筛选框按中文/日文/公司名关键字过滤）
2. 点「＋ 添加到列表末尾」追加记录，或选好区段后直接按 **Enter**；重复添加相同区段会有提醒
3. 步行 / 公交 / 打车段：在标签段输入框填站名（中文或日文，输入时自动联想补全），点对应按钮添加；起终点都留空＝接驳段，自动连上前后的两段
4. 要在任意位置插入：先在左侧选好区段，再点目标行的「⤵ 插入」按钮，即插到该行下方
5. 每行可 **上移 / 下移 / 删除**，也可**拖拽排序**；行首 **☀️/🌙** 按钮切换单条记录的白天/夜间；点击任意一行可把该行**回填**到左侧选择器微调
6. 误操作可点「↩ 撤销」或按 **⌘/Ctrl+Z**，支持连续撤销
7. 终点旁的 **⚡** 表示与下一段起点不衔接（渲染时会跳跃），记录数旁会汇总不衔接处数
8. 「导入」可粘贴已有行程文本（箭头格式 / 标签行 / 旧逗号格式均可）批量载入修改
9. 右下方「预览导出文本」可实时查看将要导出的内容
10. 点「导出 TXT」下载文件，或「复制文本」复制到剪贴板
11. 线路/站名默认显示**中文**（站名后附日文注音）；右上角「中文站名」开关可切换导出为日文原名
12. 右上角「🌙/☀️」切换**夜间模式**；首次打开自动跟随系统深色偏好，之后记住你的选择

### 输出格式

每行一段，`# 白天` / `# 夜间` 模式行按各条记录的昼夜状态在变化处自动插入（行首 ☀️/🌙 切换单条记录；渲染时夜间段底图压暗），这正是 lvji 渲染器识别的行程格式：

```
# 白天
JR山手线 品川 → 涩谷
# 夜间
御堂筋线 梅田 → なんば
步行 梅田
打车 東京 → 横浜
```

- 线路段：`线路名 [起点] → 终点`（起点省略时自动接上一段终点）
- 步行 / 公交 / 打车：`步行 [起点] → 终点`，只填终点则从上一段终点出发；只写标签名（如单独一行 `打车`）＝接驳段，自动连上上一段终点与下一段起点
- 公交按直线绘制、打车为琥珀黄直线，均由渲染器配色

取消「中文站名」勾选则输出日文原名（`JR山手線 品川 → 渋谷`）。记录自动保存在浏览器 localStorage，下次打开不丢失。

## 维护说明

云端版没有数据重建命令。本地若保留测试脚本，可运行 `node 生成器/scripts/test_ui.js`；
旧构建脚本依赖未随仓库提供的 `data.station_zh`，不能直接假定可用。
修改页面后应检查加载、地区/线路/站点选择、添加与调整行程、
日夜标记及视频行程导出。站表用于编辑输入，不能代替真实轨道寻路或运营信息核实。
中文站名无映射时保留日文原名，新干线按站表中的主地区归类。
