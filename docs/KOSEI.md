# 湖西线解析修复

## 数据依据

2026-09-11 读取 OSM 原始 relation/full 数据并检查：

- [1832686 湖西线本线](https://www.openstreetmap.org/relation/1832686)：682 个非站台 way、21 个提取站点，覆盖山科—近江塩津，不包含敦贺。
- [19142520 湖西线普通（敦贺→京都）](https://www.openstreetmap.org/relation/19142520)：398 个非站台 way、24 个提取站点，1336 个轨道节点组成一个连通网络，所有提取站点都位于该网络上。

项目几何寻路可得到比良→近江舞子约 2.24 km、近江舞子→敦贺约 59.37 km。
这证明本次需要的轨道数据存在，不代表检查过全部班次、停站规则或时刻表。

## 代码变化

1. `discover_catalog()` 的普通 route 查询加入 `route=train`；此前只查 railway/subway/light_rail/tram，可能漏掉列车服务关系。
2. 新增 JR Kosei Line／JR湖西線／湖西線／湖西线等别名，直接选择已核实覆盖京都—敦贺的 19142520，避免先触发全量发现，也避免误选止于近江舞子的短交路。

19142520 的 OSM 服务方向写作敦贺→京都。当前渲染器按无向轨道图提取几何，按用户起终点决定绘制方向，因此也能用于反向区间；这不是反向班次或无需换乘的证明。
近江塩津—敦贺在基础设施上属于北陆本线，使用这个列车关系不会把整段强行解释为湖西线本线。
数据源会变化，若后续关系不再覆盖端点，应重新核对，不得擅自把铁路段改为 walk。

别名选择和 train 发现查询有离线回归测试；实际 OSM 几何验证数据保留本地 output/，不提交用户记录或地图原始缓存。
